# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How Can You Contribute?

### 1. Reporting Bugs
If you find a bug in the source code or documentation, please submit an issue on GitHub. Include:
- A clear description of the bug.
- Steps to reproduce the issue.
- Expected vs. actual behavior.

### 2. Suggesting Enhancements and Ideas
Have an idea for a new feature or improvement? Open an issue to discuss your proposal with the community. We love hearing new ideas!

### 3. Submitting Code Changes (Bug Fixes & Enhancements)
1. Fork the repository.
2. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
